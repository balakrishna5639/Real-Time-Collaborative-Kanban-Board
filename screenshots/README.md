### Multi-User Live Collaboration Demo
To demonstrate live collaboration:
1. Open Browser Window 1 (e.g. Chrome) and log in as **Rahul Sharma** (Hyderabad).
2. Open Browser Window 2 (e.g. Incognito or Edge) and log in as **Priya Patel** or **Arjun Reddy** (Hyderabad).
3. Move or create a task in Window 1 — Window 2 updates immediately without refreshing!
4. Try logging into Browser Window 2 as **Sneha Rao** (Bangalore) — notice that Bangalore tasks are completely isolated from Hyderabad!
